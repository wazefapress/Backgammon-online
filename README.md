# 🎲 لعبة الطاولة الاحترافية - أونلاين (Professional Backgammon)

لعبة طاولة متكاملة ومتجاوبة مصممة خصيصاً للهواتف الذكية والأجهزة الذكية، تدعم اللعب الفردي ضد الذكاء الاصطناعي (الكمبيوتر) أو اللعب الجماعي أونلاين مع الأصدقاء في الوقت الفعلي عبر تقنية WebSockets[cite: 1, 2].

---

## ✨ المميزات والخصائص الرئيسية

* **🎮 وضعين للعب:**
  * **اللعب ضد الكمبيوتر:** تحدى الذكاء الاصطناعي محلياً بدون الحاجة لإنترنت.
  * **اللعب أونلاين مع صديق:** أنشئ غرفة خاصة واحصل على كود فريد مع زر "نسخ الكود" لتشاركه مع صديقك فوراً، أو انضم لغرفة موجودة عبر إدخال الكود.
* **🎲 نرد تفاعلي ثلاثي الأبعاد:** نرد بتصميم حقيقي وعصري يتضمن حركات (أنيميشن) واقعية عند الرمي[cite: 1].
* **📱 تصميم متجاوب بالكامل:** 
  * مخصص للوضع العمودي (Portrait Mode) مع شاشة إجبار على تدوير الهاتف في حال الوضع الأفقي[cite: 1].
  * استخدام وحدة القياس الحديثة (`dvh`) لحل مشاكل قص الشاشة من الأسفل في متصفحات الجوال[cite: 1].
* **💬 نظام دردشة فوري (Chat System):** شاشة محادثة داخلية تتيح التواصل بين اللاعبين أثناء اللعب، مع إمكانية تصغيرها وسحبها في أي مكان على الشاشة[cite: 1].
* **🎵 مؤثرات صوتية متكاملة:** أصوات حصرية وواقعية لرمي النرد، تحريك القطع، وصوت مخصص للاحتفال بالفوز أو إعلان الخسارة[cite: 1].
* **🔍 تفاعل مرئي متطور:** خاصية تكبير الأحجار (Zoom Preview) عند اللمس أو المرور فوقها لسهولة رؤيتها على الشاشات الصغيرة[cite: 1].

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **الواجهة الأمامية (Frontend):** 
  * HTML5 / CSS3 (Flexbox & CSS Grid)[cite: 1]
  * Vanilla JavaScript (ES6+)[cite: 1]
  * **Socket.io Client** للاتصال اللحظي[cite: 1]
  * **Howler.js** لإدارة وتشغيل المؤثرات الصوتية[cite: 1]
* **الخلفية والسيرفر (Backend):** 
  * Node.js
  * Express.js[cite: 2]
  * **Socket.io** لإدارة الغرف وتزامن الحركات والنرد بين اللاعبين[cite: 2]
